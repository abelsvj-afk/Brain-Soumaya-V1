# Reference-Image Prompts for the Worlds (ChatGPT image generation)

**For the owner — paste these into ChatGPT image generation (his pick: best image quality). Gemini works as a backup, but generations run out fast on his plan.**
**What the images are for:** reference images to generate GLB 3D models from (image-to-3D). Each prompt is written so the picture comes out clean, single-subject, and usable — not just pretty.
**How to use them:** generate 2–4 variations per prompt, keep the one where the shape reads clearly at a glance, then feed that image to the GLB generator. For any single object (station, ship, tree), a clean background and a three-quarter view work best for image-to-3D. For whole-world shots, use them as art direction for the scene build, not as a direct model source.
**General rules baked into every prompt:** no text, no watermark, no UI, no logos, no people in close-up, cinematic game concept art, consistent palette (warm sodium-amber = working/inhabited light, cold indigo = deep space, pale cyan = navigation lights only).
