# Phone Run Sheet — Growing Place Mockup (owner's device session)

*The §11 verdict requires the owner's phone. ~15 minutes of active steps + an optional soak. Everything is a labeled fixture — nothing here touches the real app or real data. If any step behaves oddly, note the time and keep going; send back whatever you capture.*

## Before you start
- Open the **growing-place standalone file** I'll send (single file, works offline once saved).
- Jot down: **phone model · OS version · the app/browser you opened it in.** (This completes the environment record.)
- Leave **Reduced motion OFF** for the first pass.

## Pass 1 — Behavior (follow the on-screen log; it prints PASS/FAIL itself)
1. **Load cargo** → wait for "A1 carry complete."
2. **Warp Far→Near**, and during the 1.2-second window tap **Cancel departure** → expect `CHECK cancel-before-departure: PASS`.
3. **Carry & place at plot** → ride the flight, watch the memory settle → expect `CHECK placement (A3): PASS`.
4. **Grow landmark** → watch the arch rise (~6s). It is a *staged fixture milestone* — the log says so.
5. **Form connection** → a trail of light draws itself between the plots.
6. **Drift Far→Near**, and mid-flight tap **Turn back** → expect `CHECK turn-back: PASS` (back at the pose you left).
7. **Drain fuel**, then **Warp** → expect a refusal line (zero fuel). Then **Return home** → expect `CHECK return-home: PASS`.

## Pass 2 — The 300-second measurement
1. Length = **300s (§11 session)** → **Run measurement**.
2. For 5 minutes: fly around — include a warp, the approach, the placement terrace, the tree. Keep the page in front.
3. When it finishes, **screenshot the measurement block** and send it.

## Pass 3 — Soak (optional, when you have the time)
Length = **900s (soak)** → run it, fly occasionally, screenshot the block at the end.

## Pass 4 — Reduced motion
1. Check **Reduced motion** → repeat a short pass: stage jumps are instant, **Grow landmark** shows the arch standing (no rising), **Form connection** appears whole.
2. Run a **300s** measurement under reduced motion too if Pass 2 went quickly; screenshot the block.

## Stills for the visual review
- **Capture still** at **Far** (dawn, terraces, the tree) and at **Near / Plots** (plots + tree) — and one **mid-rise** if you catch the arch halfway. Send the PNGs.
- Optional: a screen recording of Far → **Warp** → Near (the approach).
