# Lore art — returned images

Generated images for the lore prompts live in this folder: `docs/lore/art/`.

Name every returned image: `NN-short-title-vK.png`

- `NN` — the prompt number, zero-padded to two digits (e.g. `01`, `07`, `28`).
- `short-title` — a short kebab-case form of the prompt's title (e.g. `first-morning`, `eternity`, `night-of-seven-doors`).
- `vK` — the variant number, K = 1–4 (generate 3–4 variants per prompt).

Example: `01-first-morning-v1.png`
